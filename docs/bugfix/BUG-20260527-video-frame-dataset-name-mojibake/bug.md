# Bug：视频抽帧输出数据集名称乱码

- ID: BUG-20260527-video-frame-dataset-name-mojibake
- 标题：新建的视频抽帧输出数据集名称出现乱码
- 严重级别：Major
- 发现日期：2026-05-27

## 现象

用户在视觉预处理 Pipeline 中执行视频抽帧后，新建的 PREPROCESSED / IMAGE 输出数据集名称显示为乱码，影响数据集列表识别、后续标注来源选择和审计追踪。

## 预期行为

- 视频抽帧输出数据集必须使用可读中文名称。
- 当 Pipeline 名称本身已是乱码或不可读文本时，输出数据集名称应回退为“源视频数据集名称 + 抽帧结果”。
- 不改变既有可读 Pipeline 名称生成输出数据集名称的行为。

## 初步根因

输出数据集名称直接使用 `pipeline.name() + " 输出"`，缺少不可读文本兜底。若 Pipeline 名称来自历史编码异常数据或前端/导入链路产生乱码，抽帧结果数据集会继承乱码。

## 影响范围

- 视觉预处理 Pipeline 运行生成的 PREPROCESSED 数据集。
- 重点影响 AUDIO_VIDEO -> IMAGE 抽帧输出。
