# Bug：数据集名称仍有乱码

- ID: BUG-20260527-dataset-name-mojibake
- 标题：数据集列表/详情仍显示乱码名称
- 严重级别：Major
- 发现日期：2026-05-27

## 现象

用户反馈在修复视频抽帧输出命名后，数据集模块仍存在乱码名称。该问题可能出现在历史数据、导入数据、上传会话或下游展示接口中。

## 预期行为

- 数据集列表、详情、标注候选、数据标准画像等对外返回的 `datasetName/name` 应尽量可读。
- 已存在历史乱码数据不应继续污染前端展示。
- 若无法恢复原始名称，应使用稳定、可追踪的兜底名称：`{类型标签}数据集-{datasetId 尾号}`。

## 初步根因

`dataset.name` 从数据库读取后直接返回到多个 API 响应，缺少统一的不可读文本兜底。前一次修复只覆盖了新建视频抽帧输出数据集，未覆盖既有历史数据和其他数据集返回路径。
