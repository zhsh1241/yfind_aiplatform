# 图片数据集标注与标注文件操作文档

## 适用范围

本操作文档适用于当前已确认范围：数据集类型仅考虑图片和影音；数据集接入方式仅考虑导入和接口；标注任务仅支持图片打标与图片分割。影音数据集可纳管、查看和作为后续能力预留，但本阶段不能创建图片标注任务。

## 一、接入数据集

1. 进入「数据管理 / 数据源管理」。
2. 点击「新建数据源」。
3. 在「接入方式」中选择：
   - `IMPORT`：导入方式，适用于图片文件或批量清单导入。
   - `API`：接口方式，适用于通过外部接口接入图片或影音数据。
4. 填写 Endpoint、`secretRef` 与共享范围后保存。
5. 点击「测试连接」，诊断为 `OK` 后点击「激活」。未测试或测试失败的数据源不能被同步任务或数据集导入引用。
6. 新建同步任务并点击「立即同步」。同步成功后系统会生成数据集版本、文件绑定和血缘记录。

## 二、创建图片数据集

1. 进入「新建数据集 / 上传向导」。
2. 数据类型只能选择：
   - `IMAGE`：图片。
   - `AUDIO_VIDEO`：影音。
3. 选择来源数据源，完成数据集草稿创建。
4. 在文件登记步骤选择可用文件对象，完成 hash/size 校验并绑定版本。
5. 发布版本后，数据集状态变为 `ACTIVE`。只有 `ACTIVE + IMAGE` 数据集可用于本阶段标注任务。

## 三、创建图片标注模板

1. 进入「标注任务管理」。
2. 点击「标签模板」。
3. 场景只能选择：
   - `IMAGE_TAGGING`：图片打标，默认生成 `RectangleLabels` 标注配置。
   - `IMAGE_SEGMENTATION`：图片分割，默认生成 `PolygonLabels` 标注配置。
4. 填写标签 Schema 后提交。模板创建后会自动发布为 `PUBLISHED`，任务创建时只能选择已发布模板。

## 四、创建并执行标注任务

1. 点击「＋ 新建标注任务」。
2. 源数据集下拉仅展示 `ACTIVE` 图片数据集；影音数据集不会进入图片标注任务入口。
3. 选择与任务场景一致的图片打标或图片分割模板。
4. 创建任务后，系统生成样本工作项并分派给标注员/审核员。
5. 标注员进入「标注工作台」保存草稿或提交审核。
6. 审核员进入「标注审核」通过或驳回结果；审核人与标注员必须分离。

## 五、发布标注数据集与标注文件

1. 所有样本审核通过后，在「标注审核」执行「质量检查」。
2. 质量检查通过后点击「发布标注数据集」。
3. 系统会生成：
   - `ANNOTATED` 数据集。
   - `PUBLISHED` 数据集版本。
   - `platform_file_object` 标注文件对象。
   - `dataset_file.fileRole = ANNOTATION_RESULT` 的版本绑定。
   - `data_lineage.transformType = ANNOTATION` 的血缘记录。
4. 发布响应会返回 `annotationArtifactFileId` 与 `annotationArtifactRole`，可在输出数据集详情的「文件信息」中查看对应标注文件。

## 六、限制说明

- 当前不支持文本标注、语音标注、视频逐帧标注、多模态标注。
- 当前不启用数据库、对象存储、流、时序、工业协议等专用 connector 作为业务入口；历史类型在后端会被归一到导入或接口口径。
- 真实外部对象存储、Label Studio 地址、Token 和 workspace/storage 策略仍以 `TODO_CONFIRM_*` 配置确认；系统不得伪造外部联通成功。
