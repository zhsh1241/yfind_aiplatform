## Label Studio official-doc notes

- Official API docs require token/API key authentication headers and project IDs for most operations.
- Project creation accepts label configuration and returns project/task counters.
- Task creation uses a `data` payload shaped by project label config and returns predictions/review fields.
- Export docs distinguish UI/API/console/snapshot export paths and warn about scale/timeout concerns.
