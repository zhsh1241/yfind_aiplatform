# PRD: F017 视觉预处理算子与预处理数据集闭环

## 用户价值
- 数据工程师可直接在平台内完成图片/视频数据集预处理，无需线下脚本拼接。
- 预处理结果自动纳管为可追溯的 `PREPROCESSED` 数据集，降低数据工程与标注团队交接成本。
- 标注管理员可直接使用已激活的预处理数据集创建任务，缩短从原始采集到可标注资产的周转时间。

## 核心能力
1. 视觉预处理算子目录
   - 图片加水印（区分预览水印与产物水印）
   - 图片质量提高（一期为传统增强）
   - 图片缩放/格式转换/去噪锐化
   - 视频抽帧（固定间隔 / 固定帧率优先）
   - 视频关键帧提取（二期优先级）
   - 视频分段与帧率/分辨率统一
2. Pipeline 模板化编排
   - 图片预处理模板
   - 视频抽帧模板
   - 视频抽帧 + 图像增强模板
3. 运行结果纳管
   - 生成 `PREPROCESSED` 数据集
   - 自动创建版本、处理摘要、产物文件清单
   - 写入 `PIPELINE` / `PREPROCESS` 血缘
4. 标注衔接
   - ACTIVE 状态的预处理数据集可在标注任务创建时被选择
   - 未激活结果集不可进入标注来源列表
   - 默认只允许“未写入不可逆产物水印”的结果集进入标注链路

## 目标流程
1. 用户从数据集列表或 Pipeline 页面选择源数据集。
2. 系统按数据类型推荐图片/视频模板和可用算子。
3. 用户配置算子参数并校验 Pipeline。
4. 运行任务，查看前后对比和处理摘要。
5. 系统生成预处理数据集草稿版本；视频抽帧默认生成图片型结果集。
6. 用户确认并激活结果数据集。
7. 标注任务页面可选择该数据集作为输入。

## 首批算子目录建议
### 图片处理
- 图片加水印
- 图片质量提高（锐化、去噪、亮度/对比度优化）
- 缩放与长宽比对齐
- 格式转换（JPG/PNG/WebP）
- 去噪/锐化

### 视频处理
- 定频抽帧
- 按时间间隔抽帧
- 关键帧提取（二期优先）
- 视频裁片/分段
- 分辨率统一
- 帧率统一

## 结果数据集定义
- 数据集类型：`PREPROCESSED`
- 数据内容类型：图片源数据集输出 `IMAGE`；视频抽帧默认输出 `IMAGE`
- 结果版本必须记录：
  - `sourceDatasetId`
  - 处理算子链
  - 每个算子参数快照
  - 输入/输出样本量
  - 跳过/失败样本统计
  - 预览样本引用

## 已确认默认决策
- 一期“图片质量提高”只承诺传统增强，不绑定模型超分引擎。
- 水印能力拆分为预览水印与产物水印；进入后续标注的数据集默认不写入不可逆产物水印。
- 视频抽帧默认产出图片型预处理数据集，以贴合后续标注工作流。
- 一期视频处理优先做固定间隔抽帧与固定帧率抽帧；关键帧提取保留为后续增强项。
- 运行成功后不自动激活，必须经人工确认后再激活。
