# Deep Interview: F017 视觉预处理算子与预处理数据集闭环

## Intent / Desired Outcome
用户希望把 `算子广场` 与 `Pipeline编辑器` 从通用占位能力进一步收敛为“视觉预处理工作台”：数据工程师可以针对图片/视频数据集选择常用处理算子，运行后直接生成 `PREPROCESSED` 数据集，并无缝进入后续打标流程。

## In Scope
- 在算子广场新增首批视觉预处理内置算子：
  - 图片：图片加水印、图片质量提高、缩放、格式转换、去噪/锐化。
  - 视频：视频抽帧、关键帧提取、视频分段、分辨率统一、帧率统一。
- 在 Pipeline 页面提供“图片预处理模板”“视频抽帧模板”等快速起步模板。
- Pipeline 运行成功后生成可纳管的 `PREPROCESSED` 数据集、版本、文件清单、处理参数摘要与血缘。
- 结果数据集支持后续在标注任务创建时被选择（前提是已激活）。
- 结果预览至少覆盖：样例前后对比、产出统计、失败条目/跳过条目摘要。
- 默认产品决策：
  - 图片质量提高一期先落传统增强（锐化、去噪、亮度/对比度优化），为模型超分留扩展 seam。
  - 水印能力区分“预览水印”和“产物水印”；进入标注链路的数据集默认不写入不可逆产物水印。
  - 视频抽帧默认产出“图片型预处理数据集”，作为后续标注的标准输入形态。
  - 视频能力一期优先支持固定间隔抽帧与固定帧率抽帧，关键帧提取排在第二优先级但仍保留算子入口。
  - 运行成功后默认进入“结果预览/确认”步骤，由人工确认后再激活数据集。

## Out of Scope
- 不新增独立“预处理中心”主菜单。
- 不覆盖音频、文本、结构化数据处理。
- 不在本期实现真实分布式视频 AI 超分/修复引擎，只保留可替换执行器 seam。
- 不修改标注工作台核心交互；仅打通数据集选择来源。
- 不做任意脚本执行型自定义算子运行沙箱。

## Decision Boundaries
- 复用 F011 的 Pipeline 编辑器 / 算子广场信息架构，避免新建平行页面。
- 复用 F009/F010 的数据集、版本、文件对象、血缘模型；输出类型统一为 `PREPROCESSED`。
- 复用 F012 的“标注任务数据集选择”契约，仅扩展让 ACTIVE 的预处理数据集进入可选列表。
- 将“运行成功 -> 结果确认 -> 激活数据集 -> 进入标注”定义为标准闭环，而不是运行成功即自动可标注。
- 将“图片质量提高”一期定义为传统增强能力，不把模型超分作为一期必选依赖。
- 将“视频抽帧 -> 图片型预处理数据集”定义为默认落地路径，而非继续保留为视频型结果集。
- 将“预览水印”和“产物水印”拆分建模，避免预览安全能力污染标注数据资产。

## Exception Scenarios
- 源数据集数据类型混杂或与算子类型不兼容时，保存/运行前阻断。
- 视频抽帧参数导致产出帧数超出阈值时，需给出预估与确认提示。
- 图片加水印算子若配置为产物落盘，且结果集目标用途是后续打标场景，应提供醒目提示，并默认禁止直接激活进入标注链路。
- 运行成功但结果数据集未激活时，不允许出现在标注任务可选数据集中。
- 任一算子失败时，应保留节点级错误、跳过数量与部分成功统计，不得静默成功。
